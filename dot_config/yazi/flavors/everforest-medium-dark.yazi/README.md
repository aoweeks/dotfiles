# Everforest Medium Dark for Yazi

Built from the official
[Yazi flavor template](https://github.com/yazi-rs/flavor-template) using the
[Everforest dark medium palette](https://github.com/sainnhe/everforest/blob/master/palette.md).

## Preview

![Everforest Medium Dark](preview.png)

## Installation

```sh
ya pkg add jcarter/everforest-yazi:everforest-medium-dark
```

```toml
[flavor]
dark = "everforest-medium-dark"
```
